# Bounded application SHiP range capture

[Issue #2](https://github.com/eosrio/hyperion-wire-plugin/issues/2) needs actual application
traffic in addition to the retained onblock capture and constructed codec cases.
[capture-wire-range.py](../scripts/capture-wire-range.py) is a standard-library driver for
a contiguous, already irreversible interval on an explicitly selected Linux node host.
It imports no plugin codec, invokes no SSH, wallet, contract action or node management command,
and requests no current-head contract ABI. Running the driver is an operator action.

The driver produces capture inputs and independent official-clio observations. It does not
establish a starting ABI frontier, certified history, Node/Rust parity, indexer/backend support,
or compatibility with the future selected Wire testnet. A successful raw capture remains
`qualification.status: incomplete`; application coverage is not inferred from a block count.

## Public pins and local process binding

Prepare a public JSON file with these exact keys. Replace every placeholder; do not put private
producer keys, provider settings or credentials in this file. Both profiles are supported as
explicit engineering source pins. The selected `node.sourceRevision` must match the profile.

```json
{
  "schemaVersion": 1,
  "profileId": "wire-sysio-7dede884-engineering-v1",
  "chainId": "<64 lowercase hex characters>",
  "httpUrl": "http://127.0.0.1:18889",
  "shipUrl": "ws://127.0.0.1:18081/",
  "node": {
    "path": "/absolute/ordinary/nodeos",
    "sha256": "<binary SHA-256>",
    "sourceRevision": "7dede884e0150d36fa788e85a119e10653ade8ca",
    "serverFullVersion": "<exact get_info server_full_version_string containing that revision>",
    "pid": 12345,
    "startTicks": "<exact /proc/PID/stat field 22 decimal text>"
  },
  "clio": {
    "path": "/absolute/ordinary/clio",
    "sha256": "<binary SHA-256>",
    "sourceRevision": "<selected clio 40-hex source revision>",
    "version": "<exact trimmed clio version client stdout>"
  },
  "genesis": {"path": "/absolute/ordinary/genesis.public.json", "sha256": "<file SHA-256>"},
  "handshakeSha256": "<exact original SHiP schema SHA-256>",
  "limits": {}
}
```

The supplied node/clio source-to-binary mapping is an operator pin. The driver verifies the
actual binary hashes, full node version and chain identity; it does not invent a compiler or
Git attestation. `/proc/PID/exe` must identify the pinned ordinary node binary, process start
ticks must match, and both HTTP and SHiP listener inodes must be owned by that PID and bound
specifically to `127.0.0.1`. The process must have exactly one explicit `--genesis-json`
argument naming the pinned public file with its exact canonical absolute path (either
`--genesis-json /absolute/path` or `--genesis-json=/absolute/path`). Relative paths, dot
components, repeated separators and textual aliases are refused; the capture driver's working
directory cannot establish a node's genesis association. Complete process arguments are never retained.
The actual public genesis bytes and their hash are retained; its chain ID is independently
required from both HTTP and SHiP status. A pre-existing data directory or a genesis argument
does not establish complete starting state. Keep separate bootstrap observations as separate
public inputs when preparing a fresh sibling node.

Only numeric IPv4 loopback root URLs with explicit ports are accepted. Redirects, DNS names,
credentials, query strings, non-loopback or wildcard listener bindings are refused. Node,
clio, genesis and HTTP identity checks happen before output creation or any SHiP block request.
The original handshake must match its expected digest before the status/range request.

## Capture and retained evidence

Wait externally until the entire intended interval is irreversible and retained in both the
trace and chain-state streams. The driver does not wait for a future interval or resume a fork.

```sh
python3 scripts/capture-wire-range.py --pins /owned/public-pins.json \
  --output /owned/new-capture-directory --start 2 --end 40
```

`--end` is inclusive; the SHiP end is encoded as `end + 1`. The range is limited to 512 blocks
(128 by default). All original schema, status and block-result payloads are retained, along with
the nested block/traces/deltas bytes. Request and ACK inputs are generated by official clio;
the exact masked outbound and unmasked/fragmented inbound WebSocket frames are also preserved.
Each oracle command retains arguments, exit code, original stdout/stderr, including exit-zero
serializer errors. Partial output from bounded command failures is marked incomplete.
An EOF or timeout during an inbound frame preserves the observed header, extended-length and
payload prefix as one `complete: false` transport record. Already complete fragments remain
separate and are not duplicated. Such a frame cannot complete a source message or earn ACK credit.

The capture uses one message in flight. Original source, nested bytes, oracle outputs, request
and ACK input files are fsynced before the next credit is issued; raw outbound frames are fsynced
before `sendall`. A returned `sendall` records acceptance by the local socket, not a server ACK
confirmation or host power-loss qualification. Parent links must match between adjacent captured
positions and the decoded signed block. The first predecessor is only an observed reference;
ancestry and ABI state before the range remain explicitly unknown. No head-ABI fallback is used.

WebSocket payloads are bounded at 16 MiB; default total received wire bytes are 64 MiB, stored
bytes 128 MiB and wall-clock time 300 seconds. The public pins may reduce these bounds or raise
them to the explicit hard maxima in the script (128 MiB wire, 256 MiB storage, 900 seconds).
At least 12 MiB of storage must be allowed; 8 MiB is reserved for a bounded failure manifest.
HTTP responses are bounded at 256 KiB. Frame, file and official-command counts are bounded too.
Individual socket and oracle deadlines cannot extend the shared monotonic deadline.
The oracle allowance is fixed before process creation; setup time consumes it. Every post-spawn
setup failure kills and reaps the owned child and closes its pipes and selector. Emergency child
reaping has a separate five-second cleanup bound and grants no further command execution.

Official `clio convert unpack_hex` accepts literal hex on its argument vector. A separate
60,000-byte input bound avoids Linux's per-argument limit. A larger valid source message is
saved as raw input and produces an explicit failed/incomplete capture with an excluded oracle;
the driver does not fabricate decoded JSON or issue credit for it. This driver therefore fits
small controlled application workloads rather than arbitrary large production blocks.

Official clio can silently omit physical streams after an upstream delta-count defect. Its JSON
is retained as an oracle observation, not proof that every physical delta was decoded. Preserve
the raw bytes for the separately qualified source-pinned transport compatibility path described
in [the codec contract](codecs.md). Captured 7d bytes cannot be relabeled as a 6508 node capture.
The manifest's `deltaFraming` explicitly records the possible upstream count defect and
`fullOracleConsumptionVerified: false`, even when official clio returns an empty JSON vector.

The output directory must be new, with ordinary non-symlink ancestors. Existing files are never
overwritten. Every artifact is created exclusively, and the final manifest records file hashes,
range membership, process/listener provenance, actual request/ACK frames, oracle exclusions and
failure causes. Errors close the socket and preserve partial evidence with a nonzero exit.
An error before the output exists simply rejects the selected input pins. No cleanup/reset or
automatic deployment operation is exposed.

```sh
python3 -B -m unittest discover -s tests -p 'test_capture_wire_range.py'
```
